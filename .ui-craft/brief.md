# São Cristóvão Entregas

Produto operacional para portaria, tablet/desktop primeiro. Objetivo em 60 segundos: receber e identificar uma encomenda com confirmação humana, ou concluir uma retirada.
Princípios: velocidade, legibilidade, mínima carga cognitiva, rastreabilidade e contexto visível de portaria. Interface institucional clara em português; sem sidebar na operação, sem gráficos decorativos.
Direção escolhida a partir do briefing e da autorização para decisões reversíveis: sans-serif de sistema, superfície clara, verde pinho para ações. Movimento 1, densidade 3, craft 7, variância 3.
Assinatura: comprovante de recebimento, código e PIN com hierarquia de recibo. Estados vazios, falha de OCR e modo demo sempre explícitos.
Restrições aprendidas: nenhuma adicional.
